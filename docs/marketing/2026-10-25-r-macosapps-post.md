## Body

Hi r/MacOSApps, I’m Kapisch, the developer of Easy Write. I used AI coding tools while building it, and this post was drafted with AI assistance.

Easy Write is a Mac menu-bar app for translating and rewriting the sentence you’re already working on. It’s designed to cut out the copy → open another app → paste → copy back routine.

For example, select a sentence in a supported text field, press **Option–Command–K**, choose **German + Formal**, and review the translation. You can then replace the selection or copy the result. Choose Informal when you want “du” rather than “Sie.”

A few things I focused on:

- Language and tone controls beside the selection.
- Saved instructions for tasks such as fixing grammar or shortening a draft.
- Per-app tone preferences when memory is enabled.

Apple’s Writing Tools and other selected-text utilities already cover parts of this workflow. My focus is putting translation, tone and reusable actions together around the text you’re editing, using Apple’s on-device model.

**Free, MIT licensed.** The current 2.0.2 download is a Developer-ID-signed, Apple-notarized DMG. It requires **Apple Silicon, macOS 26 or later, and Apple Intelligence enabled with its model ready**. Accessibility permission is needed to read the selection and support replacement. Some text fields won’t expose a usable selection.

Text processing stays on your Mac. History is opt-in and stored locally; the app has no telemetry. Optional update checks and downloads use the website and GitHub.

[Website and download](https://www.onekapisch.com/products/easy-write/) · [Source](https://github.com/onekapisch/easy-write) · [Privacy and data handling](https://github.com/onekapisch/easy-write/blob/main/SECURITY.md)

If you try it, I’d appreciate reports on which apps handle selection and replacement well. For a problem report, the app name, macOS version and a disposable example are more useful than sharing private text.
