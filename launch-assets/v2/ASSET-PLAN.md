# Easy Write 2.0 launch asset plan

Approved scope: the screenshot direction preview, with the owner's added menu-bar panel and
notch motion. Daylight is the primary treatment; Midnight is an alternative hero. Website
implementation and publication are not authorized by this asset task.

## Deliverables
- Real SwiftUI Bar, menu-bar panel, reader and custom-action screenshots with synthetic data.
- Daylight hero, Midnight alternative, menu-bar context, tone, reader and actions compositions.
- A native SwiftUI notch animation recording using the production HUD view and spring,
  exported as a 60 fps MP4, WebM and a smaller GIF. The backdrop and timings are staged.
- A static notch poster, GitHub social image, web-optimized images, gallery and manifest.
- A separate proposed website redesign, including truthful release and compatibility gates.

## Execution
1. Add an asset acceptance test and confirm it fails on the missing deliverables.
2. Add a developer-only export entry point, isolated settings and native screenshot rendering.
3. Record only the owned demo view, never the user's desktop, messages or clipboard.
4. Encode distributable media. Keep intermediate frames out of Git.
5. Inspect images, sample animation frames, resolution, duration, frame rate and size.
6. Run the app self-tests and asset acceptance tests; document remaining limitations.

## Design and claims
Native typography, ink #24212E, paper #F6F4F9, violet #7C5CFF, muted lavender #D4C9F0.
One benefit per composition. No invented usage figures, reviews or unverified app logos.
The motion is a recording of the production SwiftUI view on a staged canvas, not evidence of
model latency or a recording of an actual translation. Text replacement remains conditional
on a verifiable selection. Public download and update claims remain release-gated.
